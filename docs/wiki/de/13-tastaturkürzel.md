# Tastaturkürzel

> [🇬🇧 English](../13-keyboard-shortcuts.md)

## Global

| Kürzel | Aktion |
| --- | --- |
| `Ctrl + K` / `Cmd + K` | Befehlspalette öffnen / schließen |
| `Ctrl + Enter` / `Cmd + Enter` | Aktives Tool ausführen |
| `Escape` | Befehlspalette schließen |

## Befehlspalette

| Kürzel | Aktion |
| --- | --- |
| `↑ / ↓` | Ergebnisse durchnavigieren |
| `Enter` | Markiertes Ergebnis auswählen |

## Befehlspalette — durchsuchbare Inhalte

Die Befehlspalette durchsucht:

- Alle 163 Tools (nach Name, Beschreibung, Stichworte)
- Gespeicherte Pipes (nach Name)
- Aktionen: Verlauf öffnen, Pipes öffnen, Über öffnen, Sprache umschalten, Dunkelmodus umschalten

## Plattform

Tastaturkürzel passen sich automatisch an: `⌘` auf macOS, `Ctrl` unter Windows und Linux. Der Tab **Einstellungen → Tastatur** zeigt die richtige Taste für die aktuelle Plattform.
