# Keyboard Shortcuts

> [🇩🇪 Deutsch](de/13-tastaturkürzel.md)

## Global

| Shortcut | Action |
| --- | --- |
| `Ctrl + K` / `Cmd + K` | Open / close command palette |
| `Ctrl + Enter` / `Cmd + Enter` | Run the active tool |
| `Escape` | Close command palette |

## Command palette

| Shortcut | Action |
| --- | --- |
| `↑ / ↓` | Navigate results |
| `Enter` | Select highlighted result |

## Command palette actions

The command palette searches across:

- All 163 tools (by name, description, keywords)
- Saved pipes (by name)
- Actions: open History, open Pipes, open About, toggle language, toggle dark mode

## Platform

Shortcuts adapt automatically: `⌘` on macOS, `Ctrl` on Windows and Linux. The Settings → Keyboard tab shows the correct key for your platform.
